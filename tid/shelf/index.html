The reference shelf

The Infinite Diaspora is a hard science fiction game. This shelf lists the real-world numbers behind its physics, its ships and its procedures. It says where each number came from and how strong that source is.

  • How to read the shelf

How to read the shelf

Each mechanic has one page. A page says what the game does, then lists the numbers the game runs. Each number has a grade, a source and a short reason. The pages also say where the game leaves reality on purpose, and where no source says anything.

The values come from the game code itself on the day the pages were written, so a page cannot show a number the game does not use. A grade tells you how strong the source is. It does not tell you that the game is right.

The grade key

A grade is always printed as a letter. See the grades page for examples.

A Primary
A primary source states the figure, and the game uses it as stated.
B Secondary
A secondary source quotes the figure, such as Atomic Rockets quoting NASA.
C Derived
The figure is arithmetic from an A or B figure, and the arithmetic is shown.
D Analogy
A real figure scaled into the setting, with the real figure and the scaling stated.
E Authored
The game chose the figure for play, and the page says where the sources are silent.
