The grades

A grade says how strong the source behind one number is. Five grades run from a figure a primary source states to a figure the designer chose.

The letter is always printed. A grade does not say the number is right for the game. It says what stands behind it.

Grade A: Primary

A primary source states the figure.

No number holds this grade yet.

Grade B: Secondary

A secondary source quotes the figure, such as Atomic Rockets quoting NASA.

No number holds this grade yet.

Grade C: Derived

Arithmetic from an A or B figure, with the working shown.

No number holds this grade yet.

Grade D: Analogy

A real figure scaled into the setting.

No number holds this grade yet.

Grade E: Authored

Chosen for play. Where the sources are silent, the page says so.
